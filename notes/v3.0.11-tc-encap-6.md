Patch effect:

- Adds explicit GUT-mode type-4 WireGuard payload length metadata in the previously unused GUT header byte 8.
- TC egress encodes type-4 length as `(wg_len - 32) / 16`, valid for WireGuard transport-data payloads.
- XDP ingress restores type-4 payload length as `32 + (len_code * 16)` instead of using the outer GUT payload length or padding-derived length.
- Handshake behavior from tc-encap-5 is preserved: type 1 -> 148, type 2 -> 92, type 3 -> 64.
- Type 4 remains variable-length, but now recovered from explicit metadata.
