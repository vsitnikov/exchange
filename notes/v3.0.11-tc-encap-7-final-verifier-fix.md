# v3.0.11-tc-encap-7 final verifier fix

The second v7 attempt failed GitHub Actions integration-test at TC verifier load:

```text
invalid access to packet, off=24 size=2, R3(id=0,off=24,r=0)
```

Cause: after `bpf_skb_store_bytes()` and `bpf_skb_pull_data()`, verifier did not retain packet range before later direct IPv4 header writes.

Fix commit in local packetveil checkout:

```text
5f98aec Defer GUT length metadata helper write
```

Patch artifact:

```text
patches/gutd-defer-gut-len-helper-write.patch
```

Patch effect:

- Computes type-4 GUT length metadata early but stores only the byte value.
- Defers `bpf_skb_store_bytes(skb, new_quic_off + 8, ...)` until after all direct packet header writes/checksum/MAC rewrite.
- Avoids invalidating packet pointers before subsequent direct packet access.

Validation in Cursor Cloud:

```text
GUT_VERSION=v3.0.11-tc-encap-7 cargo build --release
cargo test --release
```

Result: build passed; 24 library tests and 13 integration tests passed.
