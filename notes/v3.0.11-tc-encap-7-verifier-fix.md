# v3.0.11-tc-encap-7 verifier fix

The first v7 attempt failed GitHub Actions integration-test at TC verifier load:

```text
R9 invalid mem access 'scalar'
libbpf: prog 'gut_egress': failed to load: -EACCES
```

Cause: `bpf_skb_store_bytes()` invalidates direct packet pointers. The code wrote GUT length metadata via helper, then continued using previously cached packet pointers for IPv4/UDP header writes.

Fix commit in local packetveil checkout:

```text
c80f42d Reload skb pointers after GUT length metadata write
```

Patch artifact:

```text
patches/gutd-reload-after-gut-len-helper.patch
```

Validation in Cursor Cloud:

```text
GUT_VERSION=v3.0.11-tc-encap-7 cargo build --release
cargo test --release
```

Result: build passed; 24 library tests and 13 integration tests passed.
