# v3.0.11-tc-encap-4 verifier fix

The first v4 attempt failed GitHub Actions integration-test at XDP verifier load:

```text
invalid access to packet, off=48 size=1, R4(id=0,off=48,r=46)
libbpf: prog 'xdp_gut_ingress': failed to load: -EACCES
```

Cause: after `bpf_xdp_adjust_tail()` the verifier only had enough range for IPv4 ETH+IP+UDP (`r=46`), then still explored the IPv6 branch.

Fix commit in local packetveil checkout:

```text
d46d130 Revalidate IP headers after GUT XDP tail trim
```

Patch artifact:

```text
patches/gutd-xdp-tail-trim-verifier-revalidate.patch
```

Validation in Cursor Cloud:

```text
GUT_VERSION=v3.0.11-tc-encap-4 cargo build --release
cargo test --release
```

Result: build passed; 24 library tests and 13 integration tests passed.
