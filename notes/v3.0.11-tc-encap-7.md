Patch effect:

- Keeps v6 explicit GUT-mode type-4 WireGuard payload length metadata in GUT header byte 8.
- Changes TC egress metadata write from direct packet-pointer assignment to `bpf_skb_store_bytes(skb, new_quic_off + 8, ...)`, after `write_gut_header()`.
- XDP ingress validates type-4 metadata against the padding byte: `wg_len - restored_wg_len == ballast_len`.
- Malformed authenticated GUT type-4 packets return `-2`; top-level XDP maps that to `XDP_DROP` so Linux does not emit ICMP UDP port-unreachable for malformed GUT.
- Handshake behavior remains unchanged: type 1 -> 148, type 2 -> 92, type 3 -> 64.
